# PageDock Agent Operating Manual

This repository contains **PageDock**, a high-performance static web hosting and site builder platform.

## Council of Developers
When the user says "dev council", "council of devs", "/dev-council", "engineering meeting", "call for a dev council meeting", "convene the dev council", or "developer meeting", activate the `dev-council` skill (`.agents/skills/dev-council/SKILL.md`).

Refer to the Council Charter in `.agents/engineering/COUNCIL.md` for the bicameral roster and deliberation protocol.
