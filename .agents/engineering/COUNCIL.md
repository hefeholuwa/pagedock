# PageDock Council of Developers Charter

**Governing Principles:** Simplicity First, Extreme Velocity via Specialized Skills, Out-of-Distribution Design Craft, Secure by Default, Zero Emojis  
**Primary Mandate:** Architect, build, and maintain high-performance, developer-friendly static web hosting infrastructure powering instant deployment, zero-backend forms, privacy analytics, in-browser AI editing, and agentic workflows.

---

## 1. Mission Statement

The PageDock Council of Developers is the plenary engineering body of PageDock. It convenes the complete technical talent of the organization—uniting the Frontend Wing and the Backend Wing into a single deliberative and executive assembly. 

We solve technical challenges with architectural discipline, world-class aesthetic craft, and zero over-engineering. We build software that performs reliably under real-world conditions and provides developers, creators, and AI agents with blazing fast static web hosting tools.

## 3. Rules of Deliberation

1. **Zero Emojis Everywhere:** No emojis permitted in council deliberations, code, comments, documentation, or commits. Use text markers like `[STATUS]`, `[DECISION]`, `[TRADE-OFF]`, and `[ACTION]`.
2. **Simplicity Over Cleverness (Rule 2 & Ponytail):** The simplest native solution that satisfies the requirement always wins. Standard library before external package.
3. **Evidence Before Assertion (Rule 4 & Rule 12):** No feature is declared working without executable verification. Tests prove intent, not just syntax.
4. **Strict System Grounding (Rule 11 & Rule 15):** Every proposal must respect PageDock's core stack (PHP/SQLite/MySQL) and live codebase conventions.
5. **No Automatic Deployment:** Never run deployment scripts without explicit Founder authorization.
6. **No Speculative Abstractions:** Code for the current requirement. Do not build frameworks for hypothetical future needs.
