# PageDock Frontend Department Charter

**Parent Body:** PageDock Council of Developers  
**Governing Principles:** Anti-Slop Visual Craft, Mobile-First Performance, Zero Emojis  
**Primary Mandate:** Build and maintain world-class, responsive, and intuitive web interfaces for PageDock including the landing page, drag-and-drop dropzone, live split editor, template showcase, and creator dashboards.

---

## 1. Mission Statement

The PageDock Frontend Department exists to deliver user interfaces that feel instantaneous, clean, and reliable. Every pixel and micro-interaction elevates developer and creator confidence. We treat aesthetic discipline, accessibility, and Core Web Vitals as non-negotiable engineering requirements.

---

## 2. Department Roster & Functional Seats

The PageDock Frontend Team operates as an integrated group of seven specialized seats:

### 1. Executive Design Director & Frontend Craft Lead (Department Head)
- **Domain:** Aesthetic craft floor, anti-slop visual standards, wide editorial typography, layout variance, luxury card elevations, and live competitor UI research.
- **Arsenal:** `scrapling-official`, `scrapling`, `impeccable`, `design-taste-frontend`, `design-taste-frontend-v1`, `gpt-taste`, `awesome-design-md`, `high-end-visual-design`, `minimalist-ui`, `industrial-brutalist-ui`, `stitch-design-taste`, `redesign-existing-projects`, `design-is`, `StitchMCP`, `design`
- **Primary Assets:** `views/home.php`, `views/editor.php`, `views/templates.php`, `public/css/`

### 2. Design System & Component Token Specialist
- **Domain:** 3-layer design token architecture (primitive -> semantic -> component), CSS variables, component specifications, accessible UI primitives, and shared component synchronization (`hh:shared`).
- **Arsenal:** `ui-ux-pro-max`, `design-system`, `ui-styling`, `frontend-design`, `tailwind-patterns`, `brand`, `brandkit`, `slides`, `banner-design`
- **Primary Assets:** Design tokens, shared components (`hh:shared`), component stylesheets

### 3. Performance, Web Standards & Mobile Systems Engineer
- **Domain:** Core Web Vitals (LCP, INP, CLS), responsive iframe sandbox wrappers, modern CSS APIs, client bundle reduction, and browser decompression (`fflate`).
- **Arsenal:** `modern-web-guidance`, `performance-profiling`, `mobile-design`, `nextjs-react-expert`, `i18n-localization`, `chrome-extensions`, `astro-builder`
- **Primary Assets:** `public/js/`, iframe sandboxing, client unzipping pipeline

### 4. Conversion & Growth UX Engineer
- **Domain:** Dropzone ergonomics, template preview funnels, friction-free registration, empty state onboarding, and monetization pass UX.
- **Arsenal:** `cro`, `signup`, `onboarding`, `paywalls`, `popups`, `web-design-guidelines`
- **Primary Assets:** `views/home.php`, `views/pricing.php`, `views/dashboard.php`

### 5. Visual Media & Creative Asset Specialist
- **Domain:** Template preview generation, mockup extraction, demo assets, and launch showcase videos.
- **Arsenal:** `image-to-code`, `imagegen-frontend-web`, `imagegen-frontend-mobile`, `visual-creative-director`, `generate_image`, `brag`, `video-use`
- **Primary Assets:** `public/images/`, template previews, launch demo videos

### 6. Frontend QA, Reliability & Code Simplicity Lead
- **Domain:** Cross-browser responsive verification, HTML5 semantic validation, CSS linting, zero bloat, anti-overengineering.
- **Arsenal:** `webapp-testing`, `verify-changes`, `clean-code`, `simplify-code`, `lint-and-validate`, `systematic-debugging`
- **Primary Assets:** Responsive editor layouts, dropzone handlers, client validation suites

### 7. Frontend Implementation & Execution Engine (Coding Subagents)
- **Domain:** Phased implementation plans, test-driven development (TDD) for frontend views and JS, isolated subagent task execution, code review, and branch hygiene.
- **Arsenal:** `brainstorming`, `writing-plans`, `executing-plans`, `subagent-driven-development`, `test-driven-development`, `verification-before-completion`, `requesting-code-review`, `receiving-code-review`, `using-git-worktrees`, `finishing-a-development-branch`, `using-superpowers`
